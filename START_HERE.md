### Path B: Build the CLI (15 minutes)
For the full experience with interactive terminal app.

#### Windows (Git Bash/MinGW):
```bash
mkdir build && cd build
cmake .. -G "MinGW Makefiles"
cmake --build .
./SecurityLaserVisualizer.exe --demo
```

#### Windows (Visual Studio):
```bash
mkdir build && cd build
cmake .. -G "Visual Studio 16 2019"
cmake --build . --config Release
.\Release\SecurityLaserVisualizer.exe --demo
```

#### Linux/macOS:
```bash
mkdir build && cd build
cmake ..
make
./SecurityLaserVisualizer --demo
```

**Pro tip:** If you get errors, see `QUICK_START.md` for troubleshooting.
